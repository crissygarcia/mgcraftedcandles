## Payments
The site currently sends the order to WhatsApp. It does NOT process online payments yet.

For production, connect a payment/order backend such as Shopify, WooCommerce, Stripe-compatible UAE setup, Telr, Network International, Ziina, or your chosen provider after confirming your business/payment requirements.

## Deployment
This is a static website and can be deployed to Netlify, Vercel, GitHub Pages, Cloudflare Pages, or traditional hosting.
